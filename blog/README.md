# 블로그 노출·유입 진단

글은 괜찮은데 사람이 안 들어올 때, 어디서 막혔는지 숫자로 찾아 주는 도구다.
글 하나하나를 12개 항목으로 채점하고, 블로그 전체를 5개 항목으로 채점한 다음,
"한 번 고치면 모든 글이 같이 올라가는 순서"로 정리해 준다.
표준 라이브러리만 쓰므로 따로 설치할 것이 없다 (파이썬 3.10 이상).

## 바로 쓰기

```bash
# 1. 전체 진단 (최근 20편) -> 진단.md
python -m blog diagnose --id 내블로그아이디 --out 진단.md

# 2. 유입 수치까지 같이 보기 (블로그 통계 > 유입분석에서 내려받아 CSV로 저장)
python -m blog diagnose --id 내블로그아이디 --stats 유입.csv --out 진단.md

# 3. 다음 4주에 뭘 쓸지
python -m blog plan --id 내블로그아이디 --out 계획.md

# 4. 글 하나만 점검
python -m blog post --url https://blog.naver.com/내아이디/223456789

# 5. 쓴 글을 릴스 대본으로 (릴스 -> 블로그 유입용)
python -m blog repurpose --url https://blog.naver.com/내아이디/223456789
```

`--id` 는 블로그 주소의 아이디다 (`blog.naver.com/<아이디>`).

## 두 번째부터는 더 짧게

아이디는 한 번만 주면 기억한다. 다음부터는 `--id` 를 빼도 된다.

```bash
python -m blog config --id ks506l --place 수원   # 저장
python -m blog config --show                     # 확인
python -m blog diagnose --out 진단.md            # --id 없이 그대로 실행
```

Tab 자동완성(명령·옵션 완성, 파일 경로 완성)은 한 줄이면 끝난다.
`blog` 라는 짧은 명령도 같이 만들어 준다.

```bash
eval "$(python3 -m blog completion bash)"   # ~/.bashrc 에 넣으면 영구
eval "$(python3 -m blog completion zsh)"    # ~/.zshrc

blog dia<Tab>            -> blog diagnose
blog diagnose --<Tab>    -> --id --limit --html-dir --save-dir --stats --detail --out
blog diagnose --stats <Tab>  -> 파일 목록
```

명령 이름을 바꾸고 싶으면 `--name 블로그` 처럼 주면 된다.

회사·학교 네트워크에서 네이버가 막혀 있으면, 글 페이지를 브라우저에서
`다른 이름으로 저장`(html)한 뒤 폴더째로 넣으면 똑같이 돌아간다.

```bash
python -m blog diagnose --id 내아이디 --html-dir ~/저장한글들 --out 진단.md
python -m blog diagnose --id 내아이디 --save-dir ~/받은글   # 다음엔 재다운 없이
```

## 왜 글은 괜찮은데 유입이 적은가

네이버에서 유입은 **채널 점수 x 글 점수 x 키워드 경쟁도** 로 결정된다.
셋 중 하나가 0에 가까우면 나머지를 아무리 잘해도 사람이 안 들어온다.
대부분 다음 다섯 가지 중 하나다. 진단 리포트가 어느 쪽인지 알려 준다.

| 증상 | 리포트에서 볼 곳 | 뜻 |
|---|---|---|
| 검색해도 내 글이 안 나온다 | 주제 집중도 | 블로그 분야가 흩어져 채널 점수가 안 쌓였다 |
| 제목으로 검색하면 나오는데 유입이 없다 | 제목에 핵심 키워드 | 아무도 검색하지 않는 말로 제목을 썼다 |
| 노출은 되는데 안 눌린다 | 제목 길이, 첫 문단 | 제목이 검색 의도에 안 맞고 첫 3줄에서 이탈한다 |
| 들어왔다 바로 나간다 | 본문 분량, 이미지, 소제목 | 체류시간이 짧아 다음부터 순위가 내려간다 |
| 예전엔 됐는데 요즘 안 된다 | 발행 주기, 유사문서 위험 | 공백이 길었거나 글이 서로 겹친다 |
| 유입은 있는데 검색이 아니다 | 검색 유입 비중(통계 CSV) | 이웃·지인 유입뿐이라 노출이 사실상 0이다 |

## 네이버 검색이 실제로 보는 것

- **C-Rank** — 글이 아니라 **블로그(채널)** 를 본다. 한 주제를 얼마나 깊게,
  얼마나 꾸준히 쓰는지가 점수다. 주제가 흩어지면 글이 좋아도 밀린다.
- **D.I.A.+** — 검색한 사람의 **의도에 대한 실제 답**이 글 안에 있는지 본다.
  직접 겪은 과정·숫자·사진처럼 "이 사람이 해봤다"는 증거가 점수가 된다.
- **스마트블록** — 지금 검색 결과는 주제별 묶음으로 나간다. 그래서 큰 키워드
  하나보다 **같은 주제의 세부 키워드 여러 개**를 깔아 두는 쪽이 유리하다.

이 도구의 채점 항목은 위 세 가지를 글에서 확인할 수 있는 형태로 옮긴 것이다.
(참고: [네이버 검색의 원리와 스마트블록](https://www.i-boss.co.kr/ab-6141-66453),
[C-Rank & D.I.A.+ 설명](https://goldenrabbit.co.kr/articles/c141E6fVK6fNlad3rI9E),
[2026년 네이버 SEO 정리](https://tilnote.io/en/pages/6abd32871bc5b55a946de798))

## 30일 순서

1. **1일차** — `diagnose` 를 돌려 깎인 항목을 확인한다. 주제 집중도가 낮으면
   주제를 하나로 좁히는 것이 1순위다. 글을 더 쓰는 것보다 먼저다.
2. **2~3일차** — 점수 낮은 기존 글 5편을 고친다. 제목에 검색어 넣기,
   첫 3줄 바꾸기, 사진 5장 채우기, 소제목 3개 넣기. **새 글보다 이게 빠르다.**
   (네이버는 수정한 글도 다시 평가한다.)
3. **4일차** — `plan` 으로 4주 계획을 받고, 노리는 키워드를 네이버에 직접
   검색해 1페이지 글들의 분량·사진 수를 확인한다. 그보다 한 단계 두껍게 쓴다.
4. **5~30일** — 주 3회(월·수·금 오전 9~11시) 발행. 글마다 같은 주제 내
   다른 글 1~2개를 링크해 묶음을 만든다.
5. **2주마다** — `diagnose --stats` 로 검색 유입 비중을 다시 본다.
   이 숫자가 올라가는지만 보면 된다. 조회수는 그 뒤에 따라온다.
6. **병행** — `repurpose` 로 잘 쓴 글을 릴스 대본으로 바꿔 올린다.
   검색 노출이 쌓이는 첫 한두 달의 빈 자리를 이게 메운다.

## 채점 항목

글 하나 (100점)

| 항목 | 배점 | 기준 |
|---|---|---|
| 제목 길이 | 8 | 15~35자 |
| 제목에 핵심 키워드 | 10 | 검색어가 제목에 그대로 |
| 제목 키워드 반복 과다 아님 | 5 | 같은 말 2회 이하 |
| 첫 문단에 키워드+결론 | 10 | 인사말 대신 결론부터 |
| 본문 분량 | 15 | 공백 뺀 1500자 이상(권장 1700) |
| 키워드 밀도 | 12 | 0.5~2.0% |
| 이미지 | 10 | 직접 찍은 사진 5장 이상 |
| 동영상 | 5 | 짧은 영상 1개 |
| 소제목 구조 | 8 | 3개 이상 |
| 태그 | 7 | 5~10개, 하나는 핵심 키워드와 동일 |
| 내 글끼리 연결 | 5 | 같은 주제 내 글 링크 |
| 광고성 문구 과다 아님 | 5 | 홍보 문구 1개 이하 |

블로그 전체 (100점)

| 항목 | 배점 | 기준 |
|---|---|---|
| 발행 주기 | 20 | 주 2회 이상, 긴 공백 없음 |
| 주제 집중도 | 25 | 1위 주제가 전체 글의 50% 이상 |
| 같은 키워드 중복 아님 | 15 | 한 키워드에 3편 이상 안 겹침 |
| 유사문서 위험 낮음 | 15 | 글 사이 본문 겹침 25% 미만 |
| 글 평균 점수 | 25 | 위 글 점수의 평균 |

## 한계

- 조회수·유입 검색어는 네이버가 공개하지 않는다. 그래서 통계 화면에서
  내려받은 CSV를 `--stats` 로 받는다. 넣지 않으면 글·채널 점검만 한다.
- 키워드 검색량(월간 조회수)은 네이버 검색광고 키워드 도구에서 봐야 한다.
  이 도구는 "내 글이 어떤 키워드로 쓰였는지"까지만 알려 준다.
- 형태소 분석기 없이 정규식으로 명사를 추정한다. "깊이", "사고"처럼
  조사·어미와 모양이 겹치는 말은 빠질 수 있다.
  중요한 말이 빠지면 `blog/keywords.py` 의 `STOPWORDS`, `GENERIC` 을 손보면 된다.
