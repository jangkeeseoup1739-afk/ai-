# 블로그 유입팀

## 규칙
- 도구는 `python -m blog` 다. 설치할 것이 없다(표준 라이브러리만 씀).
- 처음 한 번은 `python -m blog config --id <아이디>` 로 아이디를 기억시키고,
  Tab 자동완성(`eval "$(python3 -m blog completion bash)"`)을 켜라고 안내한다.
  그다음부터 모든 명령에서 `--id` 를 뺀다.
- 네이버가 막힌 환경이면 바로 말하고, 글을 저장해 `--html-dir` 로 받는 길을 안내한다.
- 조회수·유입 검색어는 공개되지 않는다. 추측해서 쓰지 말고, 블로그 통계에서
  내려받은 CSV를 `--stats` 로 받는다. 없으면 "유입 수치는 빠졌다"고 명시한다.
- 단계마다 짧은 표로 보여준다. 고칠 글 목록만 OK를 받고, 나머지는 끝까지 간다.

## 1. 진단
- `python -m blog diagnose --id <아이디> --limit 20 --save-dir ~/받은글 --out 진단.md`
- 먼저 블로그 전체 5개 항목(발행 주기, 주제 집중도, 키워드 중복, 유사문서, 글 평균)을
  보여준다. 여기가 낮으면 글을 더 쓰라고 하지 말고 **주제를 좁히라**고 말한다.
- 그다음 "가장 많이 깎인 항목" 상위 3개를 집어 준다. 이게 작업 순서다.

## 2. 고칠 글 고르기
- 점수 낮은 5편을 표로 보여주고 OK를 받는다. 각 글마다 고칠 것 3개까지만 적는다
  (제목, 첫 3줄, 분량/사진/소제목 중 깎인 것).
- 새 글보다 기존 글 수정이 먼저다. 네이버는 수정한 글도 다시 평가한다.

## 3. 키워드
- `python -m blog keywords --id <아이디> --place <지역>` 으로 주력 주제와 롱테일 후보를 뽑는다.
- 후보는 사용자가 네이버에 직접 검색해 1페이지 글의 분량·사진 수를 확인하도록 안내한다.
  검색량 수치가 필요하면 네이버 검색광고 키워드 도구를 쓰라고 말한다(이 도구는 검색량을 모른다).

## 4. 발행 계획
- `python -m blog plan --id <아이디> --weeks 4 --per-week 3 --out 계획.md`
- 주 3회, 월·수·금 오전 9~11시. 유형(방법/후기/비교/실패/목록/가격/질문)을 돌려 쓴다.
- 같은 주제 내 글끼리 링크를 걸어 묶음을 만들게 한다.

## 5. 다른 유입 경로
- 잘 쓴 글은 `python -m blog repurpose --url <글주소>` 로 릴스 대본을 만들고,
  이어서 reels-edit-team 스킬로 편집한다. 검색 노출이 쌓이기 전 한두 달을 메우는 길이다.

## 6. 마무리
- 진단.md / 계획.md 경로를 알려주고, 요약을 보여준다
  (글 평균 점수, 가장 많이 깎인 항목 3개, 고칠 글 수, 4주 계획 편수).
- 2주 뒤에 `diagnose --stats` 를 다시 돌려 **검색 유입 비중**이 올라갔는지만 보라고 말한다.
